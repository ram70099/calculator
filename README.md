# Automatic Attendance System using Face Recognition 🎯

This project is an Automatic Attendance System that uses **Facial Recognition** to mark student attendance automatically.

## 📌 Features
- Facial Recognition for Student Identification
- Automatic Attendance Marking
- Calendar View for Attendance Records
- Attendance Percentage Calculation
- Holiday Detection with Auto Absent Calculation
- Secure Login System

## 💻 Technologies Used
### Frontend:
- React.js
- Framer Motion
- TailwindCSS

### Backend:
- Django
- MySQL Database
- Face Recognition Library (OpenCV)

## 📊 Database Tables
- `student_table`
- `student_attendance`
- `holiday_table`
